## 3. Denetimde **doğru** bulunan davranışlar

Bunlar incelendi, hata değiller:

* `/readyz` canlı upstream'e **dokunmaz**; `127.0.0.1`/`localhost` hedefi bilinçli
  olarak `not_ready` döner (testte 503 görülmesi beklenen davranıştır).
* `/curl` içinde `authorization` başlığı yoksa oturum **cookie-only** moda geçer
  (tam kimlik anlık görüntüsü kuralı); çerez aynı cURL'de varsa istek çalışır.
* `build_page_headers` `Authorization` göndermez: ısıtma/sayfa isteği tarayıcı
  gezinmesi gibi görünmeli.
* Kota (429), kimlik (401) ve damga (409) hataları devre kesiciyi **açmaz**.
* `stream_completion` istemci koptuğunda `GeneratorExit`/`CancelledError`
  yolunda `yield` etmez; `[DONE]` yalnızca açık bağlantıya yazılır.
* Hesap havuzu tek hesaplı kurulumda isteği bütçe yüzünden **reddetmez**
  (bütçe yalnızca tercih sırasıdır); sert kısıt yalnızca gerçek kilit + cooldown.
* Admin uçlarının tamamı `api_key_dependency` ile korunur; yanıtlar token/cookie
  değeri döndürmez (`/v1/admin/auth`, `/v1/admin/config` maskeli).

## 4. Ağ testi (yeniden üretmek için)

Sahte upstream sözleşmesi: `GET /` (damga başlığı), `GET /c/{id}`, `POST
/nextjs-api/stream/create-evaluation` (mod: `ok` / `conflict` / `conflict_then_dead`
/ `dead`), `POST /__control`, `GET /__state`.

Kapsanan kontroller — hepsi geçti:

1. `/healthz` 200, `/readyz` anlamlı, anahtarsız 401, `/v1/models` → `['max']`
2. Non-stream tamamlama içeriği, SSE akışı (`data:` + `[DONE]`)
3. `Authorization` + **tazelenmiş** damga (`dpl_live`) + referer + cookie jar
4. 409 → damga düşür → `upstream_refresh_required` (devre kesici kapalı kalır)
5. 409 → damga düşür → 401 → `upstream_unauthorized` + `upstream_session_dead`
6. `/cookie` → yeni token sonraki istekte, yanıt token sızdırmıyor
7. `/curl` → yeni çerez + referer yolu
8. `/capture` → tarayıcı yokken açıklayıcı 400
9. `/admin/config` + `/admin/auth` maskeli
10. Bilinmeyen model: non-stream 404, **stream 404** (200 + boş gövde değil)
11. 2 MB gövde → 413, `/metrics` sayaçları + kardinalite koruması
12. Keepalive kendi kendine istek atıyor; log'da `upstream_session_dead`,
    `deployment_stamp_stripped`, ham token **yok**, `response already started` yok
13. Kimlik tazeleme: boş havuz çerezle doluyor; eski token'lı kurulumda `/cookie`
    sonrası istek **taze** token ile gidiyor

## 5. Bilinerek yapılmayanlar

* **Akış ayrıştırıcısında bilinmeyen kod toleransı**: 1–2 karakterlik bilinmeyen
  kodlar (`k:`, `10:`) şu an düşürülür. Protokol içi kodlar JSON taşıdığı için
  gerçek dünyada karşılığı yok; davranışı değiştirmek yeni kodları metin sanma
  riski taşır. Gözlem gerekirse `raw_code="unknown"` sayacı eklenmeli.
* **Stream sırasında `gzip`**: `GZipMiddleware` akışa da uygulanır (Starlette
  parça parça sıkıştırır). Ölçülen bir gecikme görülmedi; ilk token gecikmesi
  `apiwrapper_time_to_first_token_seconds` ile izlenebilir.
* **`SessionManager.invalidate`** kullanılmıyor (ölü kod). Hesap etiketli
  anahtarları silemediği için çağrılırsa etkisiz olurdu; çağıran yok.
